# Changelog

The extension and the `lgit` binary it bundles are released together, under
one version number. Every change to either one is recorded in the project
changelog:

**[CHANGELOG.md on GitHub](https://github.com/fabriziosalmi/l0-git/blob/main/CHANGELOG.md)**

Release artefacts (the `.vsix` and the standalone binaries) are attached to each
[GitHub release](https://github.com/fabriziosalmi/l0-git/releases).
